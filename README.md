# Prompt Weaver

Монорепозиторий платформы шаблонов промптов и адаптивного обучения.

- [backend](backend/README.md) — серверные сервисы и тесты.
- [frontend-mobile](frontend-mobile/README.md) — приложение Kotlin Multiplatform для Android и iOS.

Проверки GitHub Actions запускаются для pull request, изменений main и вручную. CI использует отдельные тестовые базы; запросы к DeepSeek не выполняются.
