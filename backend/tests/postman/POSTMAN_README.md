# REST API: тесты Postman CLI

Коллекция проверяет регистрацию, вход, ротацию и отзыв токенов, каталог, правила и сборку промптов. Каждый запуск создаёт новую учётную запись; запускайте только на изолированном тестовом окружении, никогда на базе с пользовательскими данными. Созданные учётные записи остаются в тестовой базе.

## Подготовка

1. Установите Postman CLI: https://learning.postman.com/docs/postman-cli/postman-cli-installation/
2. Запустите отдельный экземпляр backend с отдельными базами `identity` и `prompts`, настроив его шлюз на `127.0.0.1:8000` или изменив `base_url` в окружении. Не направляйте коллекцию на рабочую базу.
3. Загрузите `infrastructure/database/demo.sql` в пустую тестовую базу `prompts` один раз. В сервисе правил должен быть доступен набор `teaching-basics-v1`, а в конфигурации сценариев — его связь с демонстрационной версией шаблона.
4. Из папки `backend` выполните:

```powershell
postman collection run tests/postman/prompt-weaver.postman_collection.json --environment tests/postman/local.postman_environment.json
```

Для запуска локальных файлов API-ключ Postman не требуется. Пароль в примере — только тестовый; не сохраняйте настоящие пароли или токены в файлах коллекции и окружения. После проверки удаляйте тестовое окружение только если вы уверены, что оно создано специально для тестов и не содержит нужных данных.
